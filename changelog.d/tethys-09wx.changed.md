- `tethys affected-tests` now distinguishes a confirmed-empty result from one the index cannot vouch for: exit 0 with empty output means confirmed no affected tests, while exit 2 (new, distinct from error exit 1) means the answer may be incomplete — a changed file is unindexed or stale, or the workspace changed since the last `tethys index`. Found tests are still printed, and one machine-readable `indeterminate: <kind>: <detail>` line per reason is written to stderr.
- Log output now goes to stderr instead of stdout, so `--names-only` output is safe to pipe into `xargs`/`grep` even with `RUST_LOG` enabled.
- File arguments now match the index regardless of spelling: `./src/lib.rs` and `src/../src/lib.rs` resolve to the same indexed file as `src/lib.rs` (previously such spellings silently produced an empty result), and relative paths no longer log a spurious "outside workspace root" warning.
